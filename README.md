# 異聞六根山 1画面カンペ

FF14「異聞六根山」の攻略用カンペです。画像は `index.html` に埋め込まれているため、GitHub Pagesでそのまま公開できます。

## GitHub Pagesで公開

1. このフォルダーの中身をGitHubリポジトリのルートへアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** を **Deploy from a branch** にします。
4. ブランチを **main**、フォルダーを **/(root)** にして保存します。

公開URLは通常 `https://ユーザー名.github.io/リポジトリ名/` です。
